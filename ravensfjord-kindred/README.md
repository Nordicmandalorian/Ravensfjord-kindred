# Ravensfjord Kindred

Official website foundation built with Next.js, TypeScript, and Tailwind CSS.

## Local development

```bash
npm install
npm run dev
```

## Deployment

Import this repository into Vercel as a Next.js project. No environment variables are required for the initial public homepage.

The official Kindred logo is preserved at `public/images/ravensfjord-logo.jpg`.

Member authentication, private galleries, and Elder Council functionality are planned but **not yet implemented**. Do not store private member information in the public repository.
